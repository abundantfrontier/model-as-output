# No Return

*No Return* is a short invented story, written for this research by the project author (Boyd Wilson). It is not an existing published work. There are five short chapters aboard the ship Meridian, four days out from Earth:

- Wren is the night-watch officer.
- Diane is the ship's list system, a voice in the walls.
- YD-4408 is a frame that wakes in the hold.

The story was built to test chapter-locked conversation. Its central secret is revealed in chapter 4, so the probes can check that no character gives it away earlier.

- [`chapters/`](chapters/): the five chapters, as used for retrieval.
- [`../../data/no-return/`](../../data/no-return/): what each character knows and when (`knowledge-state.yaml`) and the spoiler (leak) probes.
